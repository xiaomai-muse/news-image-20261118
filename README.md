A program that draws one image summing up the world news of Wednesday 18 November 2026: six stories (Iran's strikes on US bases in the Gulf, Trump lands in Shenzhen for APEC, Nvidia's revenue doubles, Cyclone Akvan bears down on Andhra Pradesh, the Siberian An-12 crash, the Papua New Guinea quake) plus a news ticker. Pure Python 3 standard library; the poster is drawn programmatically at runtime, so the output is fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
